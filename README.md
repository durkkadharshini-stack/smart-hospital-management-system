# Smart Hospital & Patient Management System

## Project Overview

The Smart Hospital & Patient Management System is a web-based application developed using Django and Django REST Framework. It helps manage patients, doctors, appointments, and treatments efficiently.

## Features

- Patient Management
- Doctor Management
- Appointment Management
- Treatment Management
- Create, Read, Update and Delete (CRUD) operations
- REST API integration
- Input validation
- Dashboard

## Technologies Used

- Python
- Django
- Django REST Framework
- SQLite
- HTML
- CSS
- JavaScript
- Git
- GitHub
- Render

## Modules

### Patient Management
- Add patient
- View patient details
- Update patient details
- Delete patient

### Doctor Management
- Add doctor
- View doctor details
- Update doctor details
- Delete doctor

### Appointment Management
- Create appointment
- View appointments
- Update appointment
- Delete appointment

### Treatment Management
- Add treatment
- View treatment details
- Update treatment details
- Delete treatment

## REST API Endpoints

- `/api/patients/`
- `/api/doctors/`
- `/api/appointments/`
- `/api/treatments/`

## Validation

The application includes validation for patient age and phone number to ensure valid data is entered.
